giant assaults both humans and fauns, out of control, charging them furiously 
using two huge tree trunks as weapons. Are you brave enough to face it and 
free the people of this scourge?

Large Models
Some Models occupy more than a single Battlefield Square. These Models are 
called Large Models. These Models occupy only a single Square during movement. 
In other words, while moving, a Large Model is considered as a normal Model, 
and then returns to occupying more Squares the moment the movement ends. 
When players need to determine the movement of a Large Model, they choose 
any of the Squares occupied by the Model and count starting from the chosen 
Square (a normal-sized Model can be used to simulate the movement of the Large 
Model). When the Large Model finishes its movement, the players place the Model 
so that the Squares occupied include the Square where it finished its movement. 
If placement is not possible because the required Squares (usually 4) are not all 
available, players refer to the following rules:
◆ If there are Models occupying the Squares, the Large Model pushes the Models 
occupying them into adjacent available Squares or the nearest available Square.
◆ If there are Scenic Elements occupying Squares, place the Large Model in 
Squares that are available or occupied by other Models. If this is not possible, 
the Large Model ends its Movement in a Square that allows its placement.
Minotaur is a Large Model which occupies 4 Squares.
New Rules
 A Large Model is considered to be targeted by an Attack with the Area Trait if at 
least one of the Squares it occupies is within the Area of the Attack.
If a Large Model is the target of an Attack with the Area Trait, it suffers only the 
Effect intended for the target, even if it occupies multiple Squares within the Area. 
If a Large Model is not the target of an Attack with the Area Trait and occupies 
more than one Square within the Area, it suffers the additional Effect only once.
Large Models and Area Effects
A Large Model always has a valid Line of Sight on all other Models and vice versa.
