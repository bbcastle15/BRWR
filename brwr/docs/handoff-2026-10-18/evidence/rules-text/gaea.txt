ROOTS TOKENS 
Some Eff ects related to Gaea place a Root 
Token in a Room. A Room may contain a 
single Root Token. If an Eff ect indicates to 
place a Root Token in a Room that already 
contains one, or indicates to place one but no 
Root Tokens are present in the game pool, do 
not place any tokens.
Root Tokens follow these rules:
• Placement: when a Root Token is placed in 
a Room, it must be placed to the left of the 
Instability Slots D , adding two Instability 
Slots to the Room. It is possible to place a 
Root Token in a Rebuilt Room.
• Instability: when  is placed in a Room 
where a Root Token is, the  must fi rst be

if available. The  on the Root Token

where the token is. If the Root Token is in 
a Rebuilt Room, only the Black Rose can 
place  on it.
• Destruction: a Root Token is considered as 
a Model (). It can be targeted like a normal 
Model and suff ers Eff ects that target the 
Room in which it is (). A Root Token 
that suff ers an Eff ect completely ignores it

the Lodge and each  on it returns to its 
owner's pool.
• Rebuilding: When a Room containing a 
Root Token is rebuilt, the Token is removed.
