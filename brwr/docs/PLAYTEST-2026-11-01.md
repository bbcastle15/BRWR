# Playtest fixes and Hex — 1 November 2026

## Implemented changes

1. Consecutive model movement keeps the 0.7-second slide and reduces its
   additional waiting time from 0.9 seconds to about 0.08 seconds.
2. Removed Evocations fade and shrink over 0.85 seconds. Authoritative removal
   is immediate; only the non-interactive visual survives temporarily. The
   portrait shader now respects the token's opacity. Applies to both host and
   receiving clients.
3. Waiting notices describe the decision, including Evocation activation and
   Nigredo's ability choice. Private choices do not expose their options or
   unrevealed card names.
4. The host supplies the same public description in the filtered remote
   snapshot. Host and remote observers therefore see equivalent information.
5. Inspecting an owned prepared Spell shows the existing gold frame on its
   selected half. The physical prepared card remains face down, and opponents
   still cannot inspect its identity or side. Single-effect cards have no
   artificial Light/Dark division.
6. Physical action flips show an English caption: Explore, Fight, Activate
   Evocation, or the applicable transformation/equipment action. A single
   replicated feedback event supplies both the flip and its caption.
7. Each phase starts with a centered sliding ribbon. It dismisses automatically,
   does not block input, and is not replayed by a duplicate network snapshot.
8. Evocation inspection uses a fabric frame, readable opaque title/stats,
   large card, and an adjacent assigned-Upgrade column. The authoritative
   Evocation remains the sole source of its displayed state.
9. Tomb Reinforcements already has its printed Instability flag. A full Command
   regression confirms that it places one Black Rose Instability, summons its
   Colossus, and awards Power. An opposing Bone Shield in the Avatar's Room
   prevents the single Instability without cancelling the other effects.
   Prevention by an Upgrade/Jinx is now reported in the public Log. The user's
   screenshot and session are consistent with this interaction, but are not
   a complete saved game proving which prevention was present at that instant.
10. An Action request opens the active player's board, including a Mage in its
    Cell with no Physical Action tokens but a Spell available for Momentum.
    Choices/F10 reconstructs that request from Game rather than a stale HUD.
    A reproduced viewer-change bug previously closed the new decision's board
    on the next frame; the new owner's requested board is now preserved, while
    the old viewer's private inspection still closes.

Hex is playable through the existing shared completeness check. All twelve
regular Spells and both starting Grimoires pass it. The newly supplied
`cerebral_worm.png` is used, and filename aliases handle `feverish_dream.png`
and `suffococation.png` without renaming the user's files. No content gate was
bypassed. Local setup and online hosting use the same school catalogue.
